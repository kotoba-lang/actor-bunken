# actor-bunken — global bibliographic knowledge actor

`actor-bunken` discovers and reconciles public library and archive records across
NDL, NCID, LCCN, OCLC, VIAF, ISBN, DOI, and ARK identifiers. Its canonical
repository is `kotoba-lang/actor-bunken`; the `actor-` prefix identifies its
governed executable role.

The actor owns a reusable bibliographic knowledge boundary, not etzhayyim's
religious Charter, Council, or organism state. Existing
`did:web:etzhayyim.com:actor:bunken`, AT Protocol namespaces, Radicle identity,
and former GitHub URL remain compatibility identities; this repository move does
not mint a new actor.

See `CLAUDE.md` for the architecture and `clojure -M:test` for the executable
contract suite.
